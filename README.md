# ↕️ Accordion Component

A sleek and interactive collapsible content widget built with **Vanilla JavaScript**. This component is commonly used for FAQs or organizing complex content into manageable sections, allowing users to expand and collapse details as needed.

### 🚀 Live Demo
👉 **[Click here to view the project live](https://tyrion122.github.io/Accordion/accordion.html)**

---

### 🛠 Tech Stack
* **JavaScript (ES6+)**: Logic for toggling visibility and handling user clicks.
* **CSS3**: Smooth transitions and styling for active states.
* **HTML5**: Semantic markup for accessible content structure.

### 💡 Project Focus & Key Concepts
This project demonstrates proficiency in UI logic:
* **DOM Traversal**: Navigating the DOM tree to select specific content panels associated with clicked headers.
* **Event Delegation**: Efficiently managing click events for multiple collapsible items.
